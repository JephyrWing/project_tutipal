## 변경과 경계

- 목록과 위젯 모두 설명 전에 `GET /api/review/items/{id}`로 현재 본인 기록을 다시 조회한다. 오래된 목록의 삭제된 요약을 그대로 전송하지 않는다.
- 설명 조회를 동기 ref로 잠가 빠른 중복 클릭을 막는다. 성공한 설명 진입은 이전 자동 진입 주소를 교체한다. 실패하면 같은 ID를 다시 조회하는 버튼을 제공한다.
- 챗봇 전송도 동기 ref로 잠근다. 오류·중단 후 같은 질문 재시도는 실패한 질문/답변 한 쌍을 교체해 질문이 중복되지 않는다. 주제/수업 변경 시 이전 요청의 후속 응답은 무시한다.
- 중지는 사용자에게 중지 상태를 표시하며 다시 질문할 수 있다. 새 초기 질문은 이전 질문 처리 여부와 별도로 판정한다.
- API/DB/모델/임계값·연속 학습 정책을 바꾸지 않는다. PT-53 댓글 10330의 정책 제안은 미승인 상태 그대로다.
- 조회 직후 다른 창에서 삭제하는 원자적 경합까지 서버에서 보장하는 변경은 아니다. 이미 챗봇에 보낸 질문/답변 삭제 정책도 이번 범위 밖이다.
