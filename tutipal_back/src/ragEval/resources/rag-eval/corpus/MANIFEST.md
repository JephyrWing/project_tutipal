## 같은 주제를 두 세션에 나눠 둔 문서 (세션 누출 검사용)

두 세션이 같은 용어를 쓰지만, 담긴 사실과 문장은 다르다. 다른 세션의 문서가 검색되면 누출이다.

| 주제 | session-a | session-b | 구별되는 사실 (예) |
|---|---|---|---|
| 해시 | `a1` 해시 테이블(메모리 자료구조), `a3` 4.3절 | `b1` 3장 해시 인덱스 | a: Java HashMap은 로드 팩터 0.75에서 두 배로 늘리고 버킷 원소가 8개 이상이면 트리로 바꾼다 / b: PostgreSQL 해시 인덱스의 기본 채움률은 75이고, 버킷을 조금씩 나눠 늘리며, PostgreSQL 10부터 WAL에 기록된다 |
| 교착 상태 | `a2` 위키백과, `a4` 제4장(자원 할당 그래프, 은행원 알고리즘, 타조 알고리즘) | `b4` 제4장(대기 그래프, 희생자 선택) | a: 은행원 알고리즘 예시(자원 12개, P0~P2), lockdep / b: InnoDB의 `innodb_lock_wait_timeout` 50초, PostgreSQL의 `deadlock_timeout` 1초, 오류 1213 / 40P01 |
| 동시성·경쟁 | `a4` 제3장(경쟁 상태, 뮤텍스, 세마포어, 모니터) | `b4` 제2·3장(갱신 손실, 격리 수준, 2PL) | a: count++ 경쟁 상태 실습(120만~150만) / b: 재고 갱신 손실, SELECT ... FOR UPDATE |
| 이진 탐색 트리와 B+트리 | `a3` 4.2절 | `b1` 2.2절 | a: AVL, 레드-블랙 트리 / b: 노드 하나에 키 약 500개, 높이 3이면 키 약 1억 2,500만 개 |
| 레드-블랙 트리 | `a3` 4.2절(TreeMap), `a4` 3쪽(CFS) | — | 세션 안의 문서끼리만 겹친다 |

문서 안에서 쓰는 제목 형식:

- Markdown: `#`부터 `#####`까지.
- TXT·PDF: `제n장`, `n.n`.
- 위키백과 각색 문서: 정의어가 한 줄로 따로 놓인 경우가 있다(예: `b2`의 "함수 종속성"). 이런 줄은 번호가 없으므로 번호 제목 규칙에는 걸리지 않는다.
